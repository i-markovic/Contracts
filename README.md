# Contracts

Projekat obuhvata tri nezavisne identifikacije iz ugovora o zakupu i podzakupu poslovnih prostora. Za svaki podatak prvo primeni instrukciju za identifikaciju na OCR tekstove u folderu lokala i njegovim podfolderima. Za čuvanje nalaza i poređenje sa listom `contract-entries` primeni odgovarajuću instrukciju za validaciju. Sve tri validacije koriste Z šifru iz kolone G i ocenjuju svaki ugovor zasebno.
